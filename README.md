# Assets · Apresentação Líderes Setembro 2026

Imagens usadas pela apresentação animada `Apresentacao_Lideres_Setembro.html`.
O HTML aponta para `https://raw.githubusercontent.com/marketingnovavidati-del/assets-apresentacao-lideres-setembro/main/<arquivo>`,
então os arquivos precisam ficar na **raiz** do repositório. Para trocar uma imagem,
suba o arquivo novo com **o mesmo nome** — o HTML não precisa mudar.

| Arquivo | Onde é usado |
|---|---|
| `nova-vida-branco.png` | logo da tela de abertura e da capa (slide 01) |
| `icone-branco.png` | símbolo no topo dos slides 02 a 07 |
| `textura-cruz.png` | textura de cruzes do slide 02 |
| `bg-desfocado.jpg` | fundo desfocado dos slides 03 a 06 |
| `next-01.webp` / `next-02.webp` | criativos Next (slide 03) |
| `opera-01.webp` / `opera-02.webp` | criativos Opera (slide 04) |
| `dados-01.webp` / `dados-02.webp` | criativos Dados (slide 05) |
| `foto-06.webp` | foto do slide 06 |
| `moedas-07.webp` | espiral de moedas do slide 07 (já com as máscaras do Figma) |
| `bg-obrigado.webp` | fundo do slide 08 |
| `efs-avatar.webp` | foto de perfil do slide 08 |
